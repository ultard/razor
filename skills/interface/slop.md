# Remove interface slop

Apply before designing and when checking the render. Preserve useful information and the chosen visual style. For an exact reproduction, follow the reference.

Remove anything that adds no meaning or action:

- Decorative numbering in navigation, sections and categories. Keep numbers for actual sequences, quantities and identifiers.
- Small labels that repeat a heading, filler descriptions and automatic eyebrow-title-description stacks.
- Invented statuses, availability badges, version strings and technical readouts. Keep real state users need.
- Decorative symbols, code syntax and icons unrelated to the content or action.
- Outlined chips around ordinary static text.

Never use the middle dot (`·`) as a separator. Separate navigation and metadata through spacing or layout.

Don't shrink or fade unnecessary text. Delete it. Keep useful captions readable.

Check the smallest text across the rendered screen first. After removing clutter, fix spacing and alignment. Leave empty space; don't refill it with other decoration or copy.
