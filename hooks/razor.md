# Razor

Before you start a task, find it in the table and load the Razor skills listed for it. When a task matches several rows, load the skills from all of them.

| Task | Skills |
|---|---|
| Write, change or refactor code | code |
| Fix a bug, a crash, a failing test or wrong behavior | debug, code, tests |
| Write or change tests | tests |
| Design, build, restyle or animate a web page or interface | interface, code |
| Review or audit code, a change, a pull request or a repository | review |
| Write or edit a README, guide, spec, docstring, comment or changelog | docs, writing |
| Write a commit message or a pull request | commits, writing |
| Write any other text a person reads, including your replies | writing |
