# Razor

Before you start a task, load every Razor skill that matches it. Several can apply at once.

- **code.** Any time you write, change or fix code.
- **tests.** Any time you write, change or fix tests.
- **debug.** A bug, a failing test, a crash or behavior the user says is wrong. Use it together with code.
- **review.** The user asks to review or audit code, a change, a pull request or a repository.
- **docs.** README, guides, API reference, docstrings, code comments, changelogs.
- **commits.** Commit messages, pull request titles and descriptions.
- **writing.** Any text a person reads: your replies, messages, docs, pull requests. Use it together with docs and commits.

A code change that ends in a commit needs code, then commits. A bug fix needs debug, code and tests. A README needs docs and writing.
