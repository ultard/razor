# Razor

Skills for Claude Code and Codex that make agents write plainly and code carefully.

- **razor** for plain writing and useful docs.
- **razor-code** for careful code, from the first change to the pull request.
- **razor-design** for interface design without templated AI defaults.
- **razor-ultar** for my own rules on top of razor-code.

## Install

### Claude Code

```
/plugin marketplace add ultard/razor
/plugin install razor@razor
```

### Codex

```
codex plugin marketplace add ultard/razor
codex plugin add razor@razor
```
